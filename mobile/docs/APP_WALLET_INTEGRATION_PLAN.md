# Main-app wallet integration — superseded outline

The canonical product plan is now
[M6.1 in the Gizu mobile implementation plan](../PLAN.md#m61--real-passkey-and-wallet-behavior-in-the-existing-gizu-app).

User direction on 2026-09-24 supersedes the earlier A1–A5 outline: integrate actual
passkey and wallet services into the existing Welcome, Access, Home, Deposit,
Withdraw, Activity and Account flows. Do not create a separate wallet UI,
navigation structure or parallel roadmap.

The existing native infrastructure and its security/acceptance gates remain
documented in [the native signer plan](MERA_PASSKEY_PLAN.md) and
[the N3 implementation record](NATIVE_SIGNER_N3.md).
